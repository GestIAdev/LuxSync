WAVE 7749.49: Strobe-dimmer coupling fix — force dimmer=1.0 when strobe>0

When two effects overlap (e.g. latin_bubbles dimmer=0.5 + Salsa Fire
strobe=1.0), the _frameIntentMap consolidates them into one intent:
{ dimmer: 0.5 (from latin_bubbles), strobe: 1.0 (from Salsa Fire) }.

The fixture receives dimmer=0.5 + strobe=1.0 → the strobe flashes at
50% brightness because the lamp is at 50%. The strobe RATE is correct
(1.0 = full speed), but the strobe BRIGHTNESS is halved by the dimmer.

This is the "strobe divided by dimmer" bug the user reported. It's not
a software coupling — it's how DMX fixtures work physically. The dimmer
controls lamp brightness, the strobe controls flash rate. Low dimmer =
dim flashes, even at max strobe rate.

Fix: in _populateValues, when writing strobe>0, also write dimmer=1.0.
This ensures any effect with an active strobe track automatically brings
the lamp to full brightness. If the same clip has a dimmer track that
comes after the strobe track in the output buffer, that dimmer track
will overwrite the 1.0 with its own value (correct — the effect's dimmer
curve takes precedence within the same clip).

The cross-clip case is now correct:
  1. latin_bubbles writes { dimmer: 0.5 }
  2. Salsa Fire writes { strobe: 1.0, dimmer: 1.0, shutter: 1.0 }
  3. Consolidated: { dimmer: 1.0, strobe: 1.0, shutter: 1.0 } → full power
