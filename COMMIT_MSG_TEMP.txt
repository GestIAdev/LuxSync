WAVE 7749.47: Add strobeRate to STRICT_PRIORITY + L3 LUMINANCE GAG

The WAVE 7749.35 dual-alias fix wrote both 'strobe' and 'strobeRate' to
the bus, but only 'strobe' was in STRICT_PRIORITY_CHANNELS. This meant:

- 'strobe'   → strict layer priority (L3 > L1 > L0) ✓
- 'strobeRate' → LTP universal (last writer wins, any layer) ✗

On fixtures that declare chDef.type='strobeRate' (not 'strobe'), the
NodeResolver reads the 'strobeRate' channel — which had NO layer
protection. L1 (Selene physicsModifier) could override L3 (.lfx curve)
via LTP, causing the 50% strobe degradation.

Fix: add 'strobeRate' to both:
1. STRICT_PRIORITY_CHANNELS — same layer priority as 'strobe'/'shutter'
2. L3_LUMINANCE_GAG_CHANNELS — L3 dominator gag includes strobeRate

Combined with WAVE 7749.46 (physicsModifier neutralized), this ensures
the .lfx strobe curve is the sole authority when an effect is active,
regardless of which channel alias the fixture profile uses.
