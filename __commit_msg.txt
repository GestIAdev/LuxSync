WAVE 7633: Fix Amnesia Bug — 2D click resets Y via placeFixture2D

ROOT CAUSE FOUND: DragDropController2D.handleUp called placeFixture2D
on EVERY pointer up, even for a simple click-to-select (no drag).

placeFixture2D → computePlanarPlacement → sets Y to
DEFAULT_ORIENTATION_HEIGHT[orientation] (e.g. 4 for 'ceiling').

So the sequence was:
1. User edits Y from 4 to 6 in FixtureInspector
2. User clicks the fixture in 2D to reselect it
3. handlePointerDown sets dragRef.current
4. handleUp fires → placeFixture2D → computePlanarPlacement → Y=4
5. FixtureInspector shows Y=4 again

Fix: handleUp now checks if the fixture ACTUALLY moved before calling
placeFixture2D. If the drag position equals the fixture's current
position (within 0.001m tolerance), it skips the placeFixture2D call.
This preserves Y edits made via the FixtureInspector.

The 3D DragDropController was already safe — it uses
updateFixturePosition (preserves Y) and checks draggedFixtureRef.current
which is only set when a real drag starts.
