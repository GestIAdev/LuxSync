WAVE 7631: Fix Amnesia Bug — syncFixturesFromTruth overwrites edited positions

The save was working (logs confirmed), but the in-memory state reverted
to the old position after saving. Root cause: TWO bugs working together.

Bug 1: syncFixturesFromTruth blind overwrite
  When useSeleneTruth detected a fixture count mismatch between the
  frontend and backend, it called syncFixturesFromTruth which blindly
  replaced ALL fixtures with the backend's truth data. The backend's
  fixtures had STALE positions (hydrated on load, never updated). This
  overwrote the user's position edits (6m) with the backend's stale
  data (4m).

  Fix: syncFixturesFromTruth now MERGES instead of overwrites. For
  fixtures that exist in both frontend and backend, it keeps the
  FRONTEND version (which has the user's edits). Only new fixtures from
  the backend are added.

Bug 2: updateFixture never synced to backend
  When the user edited a fixture position in the UI, updateFixture
  updated the stageStore but never told the backend. The backend's
  TitanOrchestrator kept the stale positions from load time. This made
  Bug 1 worse — the backend's truth data was always stale.

  Fix: updateFixture now calls lux.aether.setFixtures() to sync
  position/rotation/orientation changes to the backend. This keeps the
  truth data in sync with the frontend's edits.
