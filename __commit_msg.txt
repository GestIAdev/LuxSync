WAVE 7629: Fix infinite loop in ExtrasAggregator (getSnapshot not cached)

Two bugs caused the "Maximum update depth exceeded" crash when changing
fixture X separation:

1. UNSTABLE SELECTOR (useOrphanPhantomChannels.ts)
   The useStageStore selector used `useShallow` with a fallback of
   `return [] as unknown[]`. This created a NEW empty array on every
   getSnapshot call. React's useSyncExternalStore detected the
   reference change and re-rendered, which called getSnapshot again,
   which returned another new [] — infinite loop.
   Fix: Replaced useShallow with direct selection of state.fixtures
   (stable reference between store updates) and a module-level
   EMPTY_FIXTURES constant for the fallback case. Removed the unused
   useShallow import.

2. SIGNATURE MISMATCH (ExtrasAggregator.tsx)
   useOrphanPhantomChannels(groups) was called with a `groups` argument
   that the hook doesn't accept (signature is `useOrphanPhantomChannels()`).
   The extra arg was silently ignored, masking the mismatch.
   Fix: Removed the `groups` argument from the call site.
