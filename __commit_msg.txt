WAVE 7618.1: Fix target mutation — read live motor output, not static anchor

The WAVE 7618 target mutation was reading channelValues['pan_base']/
['tilt_base'] which contain the STATIC anchor (0.5) from
_manualOverrides, not the live pattern output. This caused the
mutated target to never change → fixtures didn't move.

Fix: Read channelValues['pan']/'tilt'] (the arbiter's fused live
output from _motorKineticOverrides) and compute the pattern deviation
as (live - anchor). This isolates the orbital displacement from the
anchor position, so:
- amplitude=0 → live == anchor → deviation=0 → no mutation (correct)
- amplitude>0 → live ≠ anchor → deviation produces 3D offset (correct)
- no pattern active → channelValues['pan'] undefined → no mutation

The L2 engine scales pattern output by 0.45 * amplitude, so max
deviation in DMX-normalized space is ~0.45. Dividing by L2_AMP_SCALE
(0.45) normalizes to [-1,+1], then multiplying by ORBIT_RADIUS (3.0m)
gives the metric offset.
