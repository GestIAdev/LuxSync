WAVE 7630: Force Global Save — purge 'Save As' hijack in CommandStrip

The Amnesia Bug: changes to fixture coordinates were lost on reload.

Root cause: CommandStrip.handleSave had a conditional branch — when
showFilePath === 'active' (the default after loadActive), clicking Save
opened a saveAsDialog instead of calling saveShow(). This saved to a
user-chosen path (e.g. 'my-show.v2.luxshow') and updated showFilePath
to that path. The default active show file (current-show.v2.luxshow)
was NEVER updated. On reload, loadActive() loads from
current-show.v2.luxshow → stale coordinates.

Fix: Purged the conditional. handleSave now unconditionally calls
await saveShow(), which writes to the active path
(current-show.v2.luxshow when showFilePath === 'active'). The saveShow
function already performs a full Global Save of the entire showFile
(fixtures, groups, scenes, stage, rigs) via atomic write
(tmp → rename → backup cleanup).

Removed the now-unused showFilePath selector from CommandStrip.
