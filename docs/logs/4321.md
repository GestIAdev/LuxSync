Por qué se rompe
AppCommander registra document.addEventListener('drop', onDrop, true) con useCapture=true: corre en fase de captura, antes que cualquier handler React.
Falta e.stopPropagation(): el evento sigue bajando por la fase de captura y luego sube por bubble. React dispara handleDrop del dropzone interno como segundo consumidor.
Resultado cuando la pestaña Theia ya está activa:
URL.createObjectURL(file) se ejecuta DOS veces sobre el mismo File → dos blob URLs distintos.
handleDrop local llama theta.start() + theta.loadVideo(urlA) inmediatamente.
120ms después, AppCommander llama theta.start() + theta.loadVideo(urlB).
loadVideo() empieza con this.teardownVideo() (@c:\Users\Raulacate\Desktop\Proyectos programacion\LuxSync\electron-app\src\theia\ThetaOrchestrator.ts:444-450), así que el segundo loadVideo destruye el videoElement del primero mientras el primero está awaiting 'loadedmetadata' con { once: true }.
El listener loadedmetadata ya nunca dispara → la promesa A queda colgada para siempre, su MediaStreamTrackProcessor queda zombi.
La promesa B compite y a veces falla por el mismo motivo si llega un drop subsiguiente.

Fix #3 — Eliminar el setTimeout(120ms) brittle de AppCommander
El setActiveTab('theia') no necesita esperar a que TheiaEngineView monte para que theta.loadVideo() funcione: el orchestrator es un singleton independiente. Pero sí necesita que el viewport haya atachado el canvas antes de start(). Con el Fix #1 en su sitio, se puede simplificar:

tsx
const onDrop = (e: DragEvent) => {
  e.preventDefault()
  e.stopPropagation()
  e.stopImmediatePropagation()
 
  const file = e.dataTransfer?.files?.[0]
  if (!file || !isSupportedGlobalVideoFile(file.name)) return
 
  const objectUrl = URL.createObjectURL(file)
  setActiveTab('theia')
 
  // Esperar UN ciclo de mount (microtask + RAF) para que TheiaEngineView
  // atache su OffscreenCanvas antes de que start() spawne el worker.
  void Promise.resolve().then(() => requestAnimationFrame(async () => {
    try {
      const theta = getThetaOrchestrator()
      await theta.start()
      await theta.loadVideo(objectUrl)
    } catch (err) {
      console.error('[Global DnD] loadVideo failed:', err)
    }
  }))
}
