Executive Summary
CONDITION NOT MET. The LiquidEngine audio pipeline does NOT inject color commands (RGB, hue, saturation, gobo, etc.) into the IntentBus or FixtureNodes. It exclusively outputs intensity values (dimmer, brightness, shutter/strobeRate). No patch required.

This is NOT a leak — it is the intended data flow.
