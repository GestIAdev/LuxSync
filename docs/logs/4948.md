# WAVE 4948.1 — FORENSIC REPORT: Decorator & Random Noise Mapping
Auditor: Cascade (Forensic Auditor)
Target: L0/L1 color pipeline + CalibrationView cache audit

## Executive Summary
**NO Math.random() or Perlin/Simplex noise found** in the active L0/L1 color hot path. However, **two time-based color generators** and **one manual-override leak from CalibrationView** were identified that can alter fixture color independently of audio and Vibe state.

| Suspect | Mechanism | Audio-Independent? | Survives App Restart? |
|---------|-----------|-------------------|----------------------|
| PlasmaRenderer (canvas) | `Math.sin(... + t)` time-driven hue | **YES** | No (must be re-activated) |
| ColorSystem `decoration` role | `audio.highMid` blend primary→accent | No (needs audio) | N/A |
| CalibrationView L2 overrides | `setManualOverrides()` on `:color` node | **YES** | **YES** (in NodeArbiter memory) |
| TestPanel raw DMX | `dmxApi.sendDirect()` bypass Arbiter | **YES** | **YES** (in hardware if cleanup missed) |

## 3. PlasmaRenderer — Time-Based Generative Color (CRITICAL)

**File:** `src/core/aether/canvas/PlasmaRenderer.ts`

```ts
@src/core/aether/canvas/PlasmaRenderer.ts:83-123
public tick(nowMs: number): void {
  const t = (nowMs - this._startMs) * TIME_SCALE   // t grows forever
  for (let y = 0; y < h; y++) {
    for (let x = 0; x < w; x++) {
      const v1 = Math.sin(x / FREQ1 + t)
      const v2 = Math.sin(y / FREQ2 + t * 0.7)
      const v3 = Math.sin((x + y) / FREQ3 + t * 0.5)
      const v4 = Math.sin(Math.sqrt(dx*dx + dy*dy) / FREQ4 + t)
      const value = (v1 + v2 + v3 + v4) * 0.25
      const hue = value * 0.5 + 0.5
      const [r, g, b] = _hsl2rgb(hue, 1.0, 0.5)
      // writes RGBA to back buffer
    }
  }
  this._manager.flip(this._canvasId)
}
```

- **Trigger:** Active if `_plasmaRenderers` set is non-empty in `TitanOrchestrator`.
- **Mechanism:** 4 sinusoids with time offset `t` → continuously shifting hue across the virtual canvas.
- **Injection path:** `PlasmaRenderer.tick()` → `AetherCanvasManager.flip()` → `PixelMapAetherAdapter.ingest()` → reads `front` buffer RGBA → emits `INodeIntent[]` with `red/green/blue` to `NodeArbiter.setEffectIntents()` (L3 ABSOLUTE OVERRIDE).
- **Audio dependency:** **ZERO.** It runs purely on `performance.now()` / `nowMs`.
- **Fixtures affected:** Any COLOR or IMPACT node that has been bound to the canvas via `PixelMapAetherAdapter.bindCanvas()` / `bindWorldSamplers()`.
- **Note:** Labeled as *"Test Pattern Producer"* for WAVE 4812 Sprint 2. Could be accidentally active in production if a canvas was never unbound.

## 6. CalibrationView / TestPanel — Manual Override Leak (CRITICAL)

**Files:**
- `src/components/views/CalibrationView/index.tsx`
- `src/components/views/CalibrationView/components/TestPanel.tsx`

### 6.1 CalibrationView sets persistent L2 manual overrides
```ts
@src/components/views/CalibrationView/index.tsx:430-445
const sendDMX = useCallback(async (channelIndex: number, value: number) => {
  const normValue = Math.max(0, Math.min(1, value / 255))
  let family = 'beam'
  if (['red', 'green', 'blue', 'white', 'amber', 'uv', 'color_wheel'].includes(channelType))
    family = 'color'

  await window.lux?.aether?.setManualOverrides([{
    nodeId: `${activeFixtureId}:${family}`,
    channels: { [channelType]: normValue },   // ← L2 override written
  }])
}, [activeFixtureId, channels])
```

**Consequence:** Every slider movement in CalibrationView writes an **L2 manual override** into `NodeArbiter._manualOverrides` for the fixture's `:color` node. The Arbiter applies this override in every subsequent `arbitrate()` call, completely replacing L0/L1 color.

### 6.2 exitCalibrationMode does NOT wipe overrides
```ts
@src/components/views/CalibrationView/index.tsx:297-308

      fixtureId: activeFixtureId,

  } catch { /* ignore */ }

```

**The comment explicitly states: "no hacer wipe global al salir de Calibración".**

The IPC handler (`AetherIPCHandlers.ts:1085-1099`) only removes the fixture from `_calibrationModeFixtures` set — it does **NOT** call `clearManualOverride()` or `clearAllManualOverrides()`.

```ts
@src/core/aether/AetherIPCHandlers.ts:1085-1099

  _calibrationModeFixtures.delete(fixtureId)   // ← Only removes from calibration set
  return { success: true }
})
```

**Result:** If a user sets a color in CalibrationView and then closes the view (or even restarts the renderer), the manual override **remains active in NodeArbiter** for that fixture's `:color` node. The fixture will show the manually set color instead of the Vibe palette.

### 6.3 TestPanel uses raw DMX bypass (survives in hardware)
```ts
@src/components/views/CalibrationView/components/TestPanel.tsx:144-157
const sendDirectDMX = useCallback(async (channelIndex: number, value: number) => {
  const absoluteAddress = dmxBaseAddress + channelIndex
  await dmxApi?.sendDirect(universe, absoluteAddress, clamped)  // ← BYPASSES Arbiter
}, ...)
```

- **Path:** Direct to DMX driver / hardware. Never goes through NodeArbiter.
- **Cleanup:** Component unmount sends zeros to previously written channels. **BUT** if the app is force-quit or the component doesn't unmount gracefully, the last DMX values remain in the hardware.
- **After restart:** If the fixture/driver has a "hold last look" behavior, the hardware may still output the TestPanel color until the new frame loop overwrites it. Since the new frame loop runs at 44Hz with new data, this usually clears quickly, but if the Orchestrator starts late or there's a startup race, the fixture can appear "stuck" on the old color.

```ts
@src/components/views/CalibrationView/index.tsx:219-248
```

## 8. Conclusion

**Three independent mechanisms can alter Front zone color in silence:**

1. **PlasmaRenderer** (WAVE 4812) — Time-based sinusoidal plasma pattern injected into L3 via `PixelMapAetherAdapter`. Pure generative color, zero audio dependency. Only active if a canvas is bound and a plasma renderer is running.

2. **CalibrationView L2 overrides** — Manual slider values are written to `NodeArbiter._manualOverrides` as L2 authority. `exitCalibrationMode` intentionally preserves them. They override L0/L1 palette until explicitly cleared.

3. **TestPanel raw DMX** — Bypasses Arbiter entirely. Values go straight to hardware. If cleanup fails, hardware holds last values.

**No Math.random(), Perlin noise, or dedicated sparkle/twinkle engine was found in the L0/L1 color pipeline.**

**No code modification performed per directive.**
